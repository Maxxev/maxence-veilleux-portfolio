# Règles pour ce projet

## Pas de tiret cadratin (—)

N'utilise jamais le caractère « — » (tiret cadratin / em dash) dans le contenu
du site — pages, dictionnaires `src/i18n/*.json`, fichiers de contenu
`src/content/**`, composants — ni dans les textes visibles générés pour ce
portfolio. Reformule avec une virgule, un point, deux points, ou deux phrases
séparées. Tolérance zéro sauf si son absence rendrait une phrase réellement
incompréhensible ; dans ce cas de dernier recours, demande confirmation avant
de l'utiliser plutôt que de trancher seul.

Ça ne s'applique pas au code (commentaires de code, docstrings) ni aux
messages de commit, seulement au texte que les visiteurs du site lisent.
